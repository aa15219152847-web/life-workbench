T1.1

⚠️ 进行中：云同步（PRO 第一付费点）

代码完成 · 差你注册 Cloudflare

纯本地存储的最大风险是"换设备/清缓存即丢数据"。云同步既是刚需卖点，也是 PRO 的核心权益。选型对比：

方案成本优点缺点建议
方案 A · 同步码
（数据加密后存对象存储/粘贴板）		¥0零后端、零账号、隐私最强同步是手动/半自动⭐ 第一步先做（1-2 天）
方案 B · Cloudflare Workers + KV免费档 10 万请求/天全自动同步 + 后续支付回调复用需要配置 CF 账号（免费）⭐ 付费墙上线前完成
方案 C · Supabase免费档 500MB功能全、有现成 Auth国内访问需注意；学习成本略高备选
执行
  1. 第一步 ✅（AI 已完成）：同步码已实现——AES-GCM 256 加密（PBKDF2 120k 迭代）+ 剪贴板兜底（syncUpload/syncDownload，commit a7b4b4e）
  2. 第二步 ⏳（等你注册）：你注册 Cloudflare 免费账号 → 把 Worker 模板（cloud-sync-worker.js）部署 → 地址填入 index.html `CLOUD_SYNC_ENDPOINT`（当前为空）
  3. 第三步：PRO 用户解锁云同步，免费用户保留本地+同步码

通过标准：两部设备数据互通，PRO 解锁后全自动同步（⏳ 待 Cloudflare 配置）
